# Figma Deliver 数据库迁移工具

## 功能说明

这个Python脚本用于将Figma Deliver的MySQL数据库从一个服务器迁移到另一个服务器。

脚本会自动：
- 连接源数据库和目标数据库
- 获取所有表结构
- **按依赖关系排序表**（先迁移父表，再迁移子表）
- **临时禁用外键检查**（避免外键约束冲突）
- 在目标数据库中重建表结构
- 复制所有数据到目标数据库
- **自动处理索引长度问题**（VARCHAR字段长度调整）
- **启用外键检查**（恢复数据库完整性约束）

## 前置条件

1. **Python 3.6+**
   ```bash
   python3 --version
   ```

2. **安装依赖**
   ```bash
   pip3 install -r requirements.txt
   ```

   或者直接安装PyMySQL：
   ```bash
   pip3 install PyMySQL
   ```

3. **数据库访问权限**
   - 源数据库需要有读取权限
   - 目标数据库需要有写入、创建表、删除表的权限

## 配置说明

迁移脚本中的数据库配置：

### 源数据库（本地）
```python
source_config = {
    'host': '127.0.0.1',
    'port': 3306,
    'user': 'root',
    'password': 'mysql@zht2182',
    'database': 'figma_deliver'
}
```

### 目标数据库（远程）
```python
target_config = {
    'host': 'node1.mysql.figma.deliver.hwhosts.com',
    'port': 3306,
    'user': 'mysqlsiud',
    'password': 'mysql!@#456',
    'database': 'figma_deliver'
}
```

## 使用方法

### 1. 测试连接（推荐先执行）

在正式迁移前，建议先测试数据库连接是否正常：

```bash
python3 migrate_database.py --dry-run
```

如果看到 `✓ 连接测试成功！` 说明两个数据库都可以正常连接。

### 2. 执行迁移

确认连接正常后，执行完整迁移：

```bash
python3 migrate_database.py
```

## 注意事项

⚠️ **重要提示**

1. **数据备份**
   - 迁移前请务必备份源数据库
   - 建议先在测试环境验证

2. **目标数据库**
   - 脚本会 **删除并重建** 目标数据库中的同名表
   - 目标数据库中的现有数据会被完全替换

3. **网络连接**
   - 确保网络稳定，特别是连接远程数据库时
   - 大量数据迁移可能需要较长时间

4. **权限要求**
   - 源数据库：SELECT 权限
   - 目标数据库：CREATE, DROP, INSERT 权限

5. **字符集**
   - 脚本使用 UTF8MB4 字符集
   - 确保源和目标数据库都支持 UTF8MB4

## 故障排查

### 连接失败

如果出现连接失败：
```
✗ 数据库连接失败: (2003, "Can't connect to MySQL server...")
```

检查：
- 数据库地址、端口是否正确
- 用户名、密码是否正确
- 防火墙是否允许连接
- 数据库服务是否运行

### 权限不足

如果出现权限错误：
```
✗ 表 xxx 创建失败: (1142, 'CREATE command denied...')
```

需要：
- 为目标数据库用户授予足够的权限
- 联系数据库管理员

### 中断迁移

如果需要中断迁移：
- 按 `Ctrl+C` 可以随时中断
- 已迁移的表不会回滚
- 可以重新运行脚本继续迁移

## 高级用法

### 修改数据库配置

如果需要迁移到其他数据库，修改脚本中的配置：

```python
# 修改 source_config 或 target_config
source_config = {
    'host': '你的数据库地址',
    'port': 3306,
    'user': '你的用户名',
    'password': '你的密码',
    'database': '数据库名'
}
```

### 选择性迁移

如果只想迁移特定的表，可以修改 `migrate_all()` 方法中的表列表过滤逻辑。

## 迁移完成后

迁移完成后，建议：

1. **验证数据**
   ```sql
   -- 检查表数量
   SHOW TABLES;
   
   -- 检查记录数
   SELECT COUNT(*) FROM users;
   SELECT COUNT(*) FROM projects;
   ```

2. **测试应用**
   - 更新应用配置连接到新数据库
   - 测试主要功能是否正常

3. **性能优化**
   - 检查索引是否正确创建
   - 运行 ANALYZE TABLE 优化查询性能
