# 渲染进度UI位置更新说明

## 更新内容

将渲染进度显示从顶部导航栏移至预览区域左上角，采用卡片式设计，类似缩略图的展示方式。

## 更新原因

原先在顶部导航栏显示渲染进度会与其他元素（项目ID、Figma链接等）重叠，影响界面美观和使用体验。

## 新的UI设计

### 位置
- **原位置：** 顶部导航栏（与项目ID、Figma链接在同一行）
- **新位置：** 预览区域左上角（预览标题栏下方）
- **定位方式：** 绝对定位（类似缩略图）

### 卡片布局

```
┌─────────────────────────────────┐
│  🔄 渲染进度              ▼     │  ← 标题栏（可点击展开/收起）
├─────────────────────────────────┤
│  状态：     [等待中]             │  ← 状态标签
│  等待时间：  30秒                │  ← 等待时间（仅等待时显示）
│  进度：     45 / 100 节点        │  ← 节点处理数量
│  [━━━━━━━━━━━━━━━━━━] 45%     │  ← 进度条
└─────────────────────────────────┘
```

### 样式特点

1. **暗黑主题：**
   - 背景：渐变色（深蓝紫色）
   - 边框：1px 实线边框
   - 阴影：8px 32px 模糊阴影
   - 背景模糊效果（backdrop-filter）

2. **尺寸：**
   - 宽度：280px
   - 高度：自适应内容
   - 收起状态：32px

3. **位置：**
   - 左边距：20px
   - 上边距：20px
   - z-index: 1000（与缩略图同级）

4. **动画效果：**
   - 脉动动画（3秒循环）
   - 阴影颜色从默认到蓝紫色过渡
   - 展开/收起过渡动画（0.3秒）

### 交互功能

1. **展开/收起：**
   - 点击卡片任意位置切换展开状态
   - 点击右上角按钮切换展开状态
   - 默认展开

2. **状态显示：**
   - **等待中：** 蓝色标签 + 时钟图标
   - **渲染中：** 蓝色标签 + 旋转加载图标

3. **信息显示：**
   - 状态标签（Tag）
   - 等待时间（仅等待状态显示）
   - 节点处理进度
   - 进度条（带百分比）

## 优势

1. **避免重叠：** 不再与顶部导航栏元素冲突
2. **信息更详细：** 卡片式设计可以展示更多信息
3. **视觉更清晰：** 渲染进度与预览内容相关，放在预览区更合理
4. **交互更友好：** 可展开/收起，不影响预览内容查看
5. **风格统一：** 与缩略图卡片风格保持一致

## 兼容性

- ✅ 保持与缩略图相同的设计风格
- ✅ 不影响现有功能
- ✅ 支持所有主流浏览器
- ✅ 响应式设计（移动端自适应）

## 测试要点

### 测试场景 1：基本显示
1. 启动渲染任务
2. 检查左上角是否出现渲染进度卡片
3. 检查卡片内容是否完整

### 测试场景 2：展开/收起
1. 点击卡片标题栏
2. 验证卡片是否正确收起
3. 再次点击验证是否展开

### 测试场景 3：等待时间显示
1. 在Token冷却期启动渲染
2. 验证是否显示"等待时间"行
3. 验证时间是否正确倒计时

### 测试场景 4：位置不冲突
1. 检查卡片是否遮挡重要内容
2. 验证与缩略图位置是否合理（一个左上，一个右下）
3. 测试不同屏幕尺寸下的显示效果

### 测试场景 5：动画效果
1. 观察脉动动画是否流畅
2. 验证展开/收起过渡动画
3. 检查加载图标旋转动画
