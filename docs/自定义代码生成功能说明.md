# 自定义代码生成功能说明

## 概述

系统已重构代码导出功能，移除了平台特定的实现（Android、iOS等），改为使用用户自定义的JavaScript脚本来生成代码。这使得系统更加灵活和可扩展。

## 功能特点

1. **平台无关**：不再绑定特定平台，用户可以自定义任何平台的代码生成逻辑
2. **脚本化**：使用JavaScript编写代码生成逻辑，灵活强大
3. **数据驱动**：系统提供节点树和图片字典，脚本负责代码生成

## 数据库更新

已添加 `ui_creater` 字段到 `users` 表，用于存储用户的代码生成脚本（最大1024KB）。

迁移文件：`migrations/008_add_ui_creater_to_users.sql`

```sql
ALTER TABLE users ADD COLUMN IF NOT EXISTS ui_creater TEXT;
```

## 使用方法

### 1. 配置代码生成脚本

1. 登录系统，进入"个人资料"页面
2. 展开"UI代码生成脚本"部分
3. 点击"查看示例脚本"可以查看脚本模板
4. 编写或粘贴您的JavaScript脚本
5. 点击"测试脚本"验证脚本是否正确
6. 点击"保存所有设置"保存脚本

### 2. 脚本规范

脚本必须实现两个函数：

#### generatePreview(context)
生成代码预览，用于在浏览器中展示代码。

**参数：** context对象，包含以下字段：
- `nodeTree`: Figma节点树数据（JSON对象）
- `imageDict`: 图片字典，格式为 `{ "节点ID": { "url": "图片URL", "localPath": "本地路径" } }`
- `config`: 导出配置 `{ imageFormat: "png", imageScale: 2.0 }`
- `projectId`: 项目ID
- `project`: 项目信息对象

**返回值：** 对象，格式为 `{ "文件名": "文件内容" }`

#### generateExport(context)
生成最终导出的代码，用于打包下载。

**参数和返回值：** 与 `generatePreview` 相同

### 3. 示例脚本

```javascript
// 预览函数 - 返回代码文件的字典
function generatePreview(context) {
    const files = {};
    
    // 生成主文件
    files["Main.txt"] = generateMainCode(context.nodeTree, context.imageDict);
    
    // 生成配置文件
    files["Config.json"] = JSON.stringify({
        projectId: context.projectId,
        imageFormat: context.config.imageFormat,
        imageScale: context.config.imageScale
    }, null, 2);
    
    return files;
}

// 导出函数 - 返回代码文件的字典
function generateExport(context) {
    // 导出和预览可以使用相同的逻辑，也可以不同
    return generatePreview(context);
}

// 辅助函数 - 生成主代码
function generateMainCode(nodeTree, imageDict) {
    let code = "// 自动生成的代码\\n\\n";
    
    // 递归处理节点树
    function processNode(node, depth = 0) {
        const indent = "  ".repeat(depth);
        code += indent + "// 节点: " + node.name + " (类型: " + node.type + ")\\n";
        
        // 如果节点有对应的图片，添加注释
        if (imageDict[node.id]) {
            code += indent + "// 图片: " + imageDict[node.id].url + "\\n";
        }
        
        // 处理子节点
        if (node.children && node.children.length > 0) {
            for (let child of node.children) {
                processNode(child, depth + 1);
            }
        }
    }
    
    if (nodeTree) {
        processNode(nodeTree);
    }
    
    return code;
}
```

### 4. 使用代码生成功能

1. 在项目Dashboard页面，点击底部的"代码预览"按钮
2. 系统会打开新窗口，展示生成的代码文件
3. 可以切换查看不同的文件
4. 可以调整图片格式和缩放比例，然后点击"刷新预览"
5. 点击"导出代码"创建导出任务，生成的压缩包可以在主页面下载

## API接口

### 生成代码预览
```
POST /figma/project/:project_id/custom/preview
```

请求体：
```json
{
    "imageFormat": "png",
    "imageScale": 2.0
}
```

响应：
```json
{
    "success": true,
    "files": {
        "Main.txt": "// 代码内容...",
        "Config.json": "{ ... }"
    },
    "message": "代码预览生成成功"
}
```

### 导出代码
```
POST /figma/project/:project_id/export/custom
```

请求体：同预览接口

响应：
```json
{
    "success": true,
    "job_id": 123,
    "message": "导出任务已创建，正在处理中..."
}
```

### 查看代码预览页面
```
GET /figma/project/:project_id/custom/code-preview?imageFormat=png&imageScale=2.0
```

## 节点树数据结构

节点树是一个递归的JSON对象，每个节点包含以下字段：

```typescript
{
    id: string;                    // 节点ID
    name: string;                  // 节点名称
    type: string;                  // 节点类型（FRAME、TEXT、RECTANGLE等）
    visible?: boolean;             // 是否可见
    absoluteBoundingBox?: {        // 绝对边界框
        x: number;
        y: number;
        width: number;
        height: number;
    };
    fills?: Array<any>;            // 填充样式
    strokes?: Array<any>;          // 描边样式
    effects?: Array<any>;          // 效果（阴影、模糊等）
    characters?: string;           // 文本内容（TEXT类型）
    children?: Array<Node>;        // 子节点数组
    // ... 更多Figma节点属性
}
```

## 图片字典数据结构

图片字典是一个对象，键为节点ID，值包含图片信息：

```typescript
{
    "节点ID": {
        url: string;          // 图片URL（Figma CDN或OBS）
        localPath: string;    // 本地路径标识（OBSKey）
    }
}
```

## 注意事项

1. **脚本大小限制**：脚本最大不能超过1024KB
2. **安全性**：脚本在沙箱环境中执行，只能访问提供的context数据
3. **性能**：避免在脚本中使用过于复杂的循环和递归，可能导致超时
4. **调试**：使用 `console.log()` 可以在服务器日志中输出调试信息
5. **错误处理**：脚本执行错误会在界面上显示，请仔细检查错误信息

## 旧功能迁移

原有的平台特定代码导出功能（Swift、Android等）已被标记为废弃，但代码仍保留以供参考。新项目应使用自定义代码生成功能。

如需将旧的平台特定逻辑迁移到新系统，可以参考 `internal/services/swift_export.go` 和 `internal/services/android_export.go` 中的代码生成逻辑，将其改写为JavaScript脚本。

## 技术实现

- **后端**：使用 [goja](https://github.com/dop251/goja) JavaScript引擎执行用户脚本
- **前端**：Vue.js + Element UI
- **代码编辑器**：Textarea（可升级为Monaco Editor等代码编辑器组件）
- **文件打包**：使用Go标准库的 `archive/zip` 创建压缩包
