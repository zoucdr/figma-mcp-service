## 变更内容

### 新增功能
✅ 在Dashboard底部的"下载优化JSON"圆形按钮上支持右键菜单
✅ 右键菜单提供"拷贝下载链接"和"下载"两个选项
✅ 支持将完整的API下载链接复制到剪贴板
✅ 自动适配现代浏览器和旧版浏览器的复制API
✅ **v1.1新增**：智能菜单位置调整，自动检测屏幕边界防止遮挡
✅ **v1.2修复**：修复URL重复拼接问题（apiDownloadUrl已包含完整URL）
✅ **v1.3修复**：统一下载数据格式，点击下载和复制链接下载的数据结构一致

### 技术亮点

1. **智能位置调整** 🎯
   - 自动检测视口剩余空间
   - 底部空间不足时自动向上显示
   - 右侧空间不足时自动向左显示
   - 确保菜单始终完全可见，不被遮挡

2. **事件处理优化**
   - 使用 `@contextmenu.prevent.native` 阻止默认右键菜单
   - 使用 `@click.stop` 防止事件冒泡
   - 延迟绑定关闭事件，避免立即触发

2. **浏览器兼容性**
   - 优先使用现代 `navigator.clipboard.writeText()` API
   - 自动降级到 `document.execCommand('copy')` 
   - 支持所有主流浏览器

3. **用户体验**
   - 菜单位置跟随鼠标点击位置
   - 点击其他区域自动关闭菜单
   - 操作成功后显示友好提示信息
   - 菜单样式与现有UI保持一致

4. **代码质量**
   - 复用现有的样式类（layer-menu-title, layer-menu-function-item）
   - 代码结构清晰，易于维护
   - 完善的错误处理和降级方案

## 使用场景

### 场景1：快速分享下载链接
用户可以右键复制链接后，通过邮件、聊天工具等方式分享给其他人。

### 场景2：API集成测试
开发者可以复制链接在Postman、curl等工具中测试API。

### 场景3：批量下载脚本
用户可以将链接用于编写批量下载脚本。

### 场景4：浏览器直接访问
用户可以将链接粘贴到浏览器地址栏直接访问。

## 注意事项

⚠️ **安全提醒**：
- 复制的链接中包含MCP Token（身份认证令牌）
- 不要将此链接分享给不信任的人
- Token泄露可能导致未授权访问

💡 **使用提示**：
- 需要先在个人资料中生成MCP Token
- Token过期后链接将失效
- 建议使用HTTPS协议以确保安全
