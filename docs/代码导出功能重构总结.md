## 系统架构

```
用户设置页面 (profile.html)
    ↓ 保存脚本
User.UICreater (数据库)
    ↓ 读取脚本
Dashboard (dashboard.html)
    ↓ 点击"代码预览"
自定义代码预览页面 (custom-code-preview.html)
    ↓ POST /figma/project/:id/custom/preview
GenerateCustomCodePreview (controllers/figma.go)
    ↓ 调用
services.GenerateCustomCodePreview (services/custom_code_export.go)
    ↓ 执行
用户的JS脚本 (goja引擎)
    ↓ 接收
context { nodeTree, imageDict, config, ... }
    ↓ 返回
{ "文件名": "文件内容" } (代码文件字典)
    ↓ 显示
代码预览页面
    ↓ 点击"导出代码"
POST /figma/project/:id/export/custom
    ↓ 创建异步任务
ExportJob (数据库)
    ↓ 执行导出
services.ExportCustomCode()
    ↓ 创建压缩包
services.CreateExportArchive()
    ↓ 完成
下载ZIP文件
```

## 核心特性

### 1. JavaScript沙箱执行环境
- 使用 `goja` 引擎执行用户脚本
- 提供 `console.log` 支持，输出到服务器日志
- 提供 `JSON.stringify` 和 `JSON.parse` 支持
- 脚本只能访问传入的 `context` 对象，确保安全性

### 2. 数据提供
系统向脚本提供：
- **节点树**：完整的Figma节点树结构（递归JSON对象）
- **图片字典**：节点ID到图片URL的映射
- **导出配置**：图片格式、缩放比例等
- **项目信息**：项目ID、项目对象等

### 3. 脚本规范
用户脚本必须实现两个函数：
- `generatePreview(context)`: 生成预览代码
- `generateExport(context)`: 生成导出代码

两个函数都返回 `{ "文件名": "文件内容" }` 格式的对象

### 4. 前端交互
- **脚本编辑**：在用户设置页面配置脚本
- **脚本测试**：点击"测试脚本"按钮验证脚本
- **示例查看**：点击"查看示例脚本"获取模板
- **代码预览**：实时查看生成的代码
- **代码导出**：异步任务，生成ZIP压缩包

## 与旧系统的区别

| 平台支持 | 固定（Swift、Android） | 任意平台（用户自定义） |

2. **执行时间**：脚本执行可能有超时限制（取决于goja配置）
