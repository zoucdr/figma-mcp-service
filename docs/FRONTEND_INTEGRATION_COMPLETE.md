### 1. 核心模块开发

**文件位置**: `web/static/js/figma-render.js`

- ✅ 创建渲染队列 (`createRenderQueue`)

#### ✅ Token 冷却提示

**场景**: Figma API 返回 code: 1001

**处理**:
```javascript
this.$alert(
    `Token 冷却中，请等待 ${error.waitSeconds} 秒后重试`,
    'Token 冷却',
    { type: 'warning' }
);
```

**显示信息**:
- ⏰ 剩余等待时间
- 🕐 下次可用时间

#### ✅ 速率限制提示

**场景**: HTTP 状态码 429

**处理**:
```javascript
this.$alert(
    'Figma API 请求过于频繁，请稍后重试',
    '速率限制',
    { type: 'warning' }
);
```

#### ✅ 通用错误提示

**场景**: API 调用失败、网络错误等

**处理**:
```javascript
this.$message.error(error.message || '操作失败');
```

## 🔄 工作流程

### 用户操作流程

```
1. 用户浏览项目列表
   ↓
2. 点击"渲染"按钮（项目级别或分组级别）
   ↓
3. 系统自动获取节点信息
   ↓
4. 显示渲染对话框
   ↓
5. 用户配置参数（格式、缩放比例）
   ↓
6. 点击"开始渲染"
   ↓
7. 创建渲染队列
   ↓
8. 自动轮询队列状态
   ↓
9. 实时更新进度条
   ↓
10. 渲染完成，显示结果
```

### 系统处理流程

```
前端请求
   ↓
获取节点信息 (GET /api/figma/project/:id/nodes)
   ↓
创建渲染队列 (POST /api/figma/manual/render)
   ↓
   ├─→ 成功: 返回 queue_id
   │   ↓
   │   开始轮询
   │   ↓
   │   每 2 秒请求一次 (GET /api/figma/render/queue)
   │   ↓
   │   更新 UI
   │   ↓
   │   ├─→ 状态 = 'completed': 显示完成
   │   ├─→ 状态 = 'failed': 显示错误
   │   └─→ 状态 = 'processing': 继续轮询
   │
   └─→ 失败: 显示错误提示
       ↓
       ├─→ Code 1001: Token 冷却提示
       ├─→ Status 429: 速率限制提示
       └─→ 其他: 通用错误提示
```

## 📝 使用说明

### 开发者使用

#### 1. 在其他页面中集成渲染功能

```javascript
// 1. 在 HTML 中引入渲染模块
<script src="/static/js/figma-render.js"></script>

// 2. 在 Vue 组件中混入
const MyApp = {
    mixins: [window.FigmaRenderMixin],
    // ...
};

// 3. 调用渲染方法
this.showRenderDialog(fileKey, nodeIds);
```

#### 2. 自定义渲染流程

```javascript
// 使用 FigmaRenderManager 直接控制
const result = await FigmaRenderManager.createRenderQueue(
    { fileKey, nodeIds, format, scale },
    onProgress,
    onComplete,
    onError
);
```

### 用户使用

#### 1. 渲染单个项目

1. 在项目列表中找到要渲染的项目
2. 点击该项目行右侧的"渲染"按钮
3. 在弹出的对话框中配置参数
4. 点击"开始渲染"
5. 等待渲染完成

#### 2. 批量渲染分组

1. 找到要渲染的分组
2. 点击分组标题右侧的"批量渲染"按钮
3. 在弹出的对话框中配置参数
4. 点击"开始渲染"
5. 等待渲染完成
