# UI 改进 - 分组渲染按钮优化 🎨

## 📋 改进内容

### 1. ✅ 移除 group.fileKey 属性

**原因**: 
- 一个分组内可能包含多个不同的 `file_key`
- group 层级不应该持有单一的 `file_key` 属性

**修改**: `web/static/js/projects.js`

```javascript
// 修改前
return {
    groupKey: groupKey,
    fileKey: fileKey,  // ❌ 移除此属性
    projects: projects,
    // ...
};

// 修改后
return {
    groupKey: groupKey,
    projects: projects,  // ✅ 只保留项目列表
    // ...
};
```

### 2. ✅ 移除分组标题的 file_key 显示

**原因**: 
- 既然 group 不持有 `fileKey`，界面上也不应显示
- 避免误导用户（分组内可能有多个不同文件）

**修改**: `web/templates/projects.html`

```html
<!-- 修改前 -->
<div class="group-header-right">
    <el-button>批量渲染</el-button>
    <!-- ❌ 移除这个 file_key 显示 -->
    <span class="file-key-badge">
        <i class="el-icon-document-copy"></i>
        {{ group.fileKey }}
    </span>
    <span v-if="group.groupName">...</span>
</div>

<!-- 修改后 -->
<div class="group-header-right">
    <el-button>批量渲染</el-button>
    <!-- ✅ 只显示分组名称 -->
    <span v-if="group.groupName">...</span>
</div>
```

### 3. ✅ 更改"批量渲染"按钮颜色

**原因**: 
- 让批量渲染功能更醒目
- 与单个项目渲染按钮（绿色）区分开来

**修改**: `web/templates/projects.html`

```html
<!-- 修改前 -->
<el-button 
    size="mini" 
    type="success"  <!-- ❌ 绿色 -->
    icon="el-icon-picture" 
    @click.stop="renderGroupNodes(group)">
    批量渲染
</el-button>

<!-- 修改后 -->
<el-button 
    size="mini" 
    type="warning"  <!-- ✅ 橙色（更醒目）-->
    icon="el-icon-picture" 
    @click.stop="renderGroupNodes(group)">
    批量渲染
</el-button>
```

### 用户操作流程

```
查看项目列表
  ↓
看到分组标题
  ↓
分组显示:
  - 分组名称（或项目名组合）

  - [🟠 批量渲染] 按钮（醒目的橙色）

  ↓

  ↓

  └─→ 多个文件: 显示确认对话框，列出所有文件
```

## 🎨 Element UI 颜色规范

| type | 颜色 | 用途 | 示例 |
|------|------|------|------|
| `primary` | 蓝色 | 主要操作 | 保存、确定 |
| `success` | 绿色 | 成功/普通操作 | 单个项目渲染 |
| `warning` | 橙色 | 警告/重要操作 | 批量渲染 |
| `danger` | 红色 | 危险操作 | 删除 |
| `info` | 灰色 | 信息展示 | 标签 |

**选择 `warning` (橙色) 的原因**:
- ✅ 比绿色更醒目
- ✅ 表示这是一个"重要的批量操作"
- ✅ 与单个项目的绿色按钮区分开来
- ✅ 符合 Element UI 设计规范
