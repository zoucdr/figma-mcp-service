# 提示词分享功能使用指南

## 功能概述

提示词分享功能允许用户将自己的 AI 节点修饰提示词分享到社区，其他用户可以查看、点赞和复制这些提示词。

## 功能特性

### 1. 分享提示词
- 用户可以在个人资料页面分享自己的修饰提示词
- 分享时需要填写标题、描述（可选）
- 分享的提示词会显示在提示词广场

### 2. 提示词广场
- 公开访问，无需登录即可查看
- 按点赞数排序显示
- 支持分页浏览
- 显示分享者、发布时间、点赞数等信息

### 3. 点赞功能
- 登录用户可以为他人的提示词点赞
- 不能为自己的提示词点赞
- 支持取消点赞
- 点赞数越多，排名越靠前

### 4. 管理功能
- 用户只能删除自己的分享
- 可以在"我的分享"中查看和管理自己的所有分享

## 使用流程

### 分享提示词

1. 登录系统
2. 进入"个人资料"页面
3. 在"AI 提示词"部分填写修饰提示词
4. 点击"分享提示词"按钮
5. 填写分享标题和描述
6. 点击"确定分享"

### 浏览提示词

1. 访问 `/share` 页面
2. 浏览所有用户分享的提示词
3. 点击"复制"按钮复制感兴趣的提示词
4. 登录后可以点赞

### 管理分享

1. 在提示词广场或个人中心查看自己的分享
2. 点击"删除"按钮删除分享
3. 删除会同时删除相关的点赞记录

## API 接口

### 获取分享列表
```
GET /share/api/shares?limit=20&offset=0
```

### 创建分享（需要登录）
```
POST /share/api/shares
{
  "title": "标题",
  "description": "描述",
  "prompt": "提示词内容"
}
```

### 删除分享（需要登录）
```
DELETE /share/api/shares/:id
```

### 点赞（需要登录）
```
POST /share/api/shares/:id/like
```

### 取消点赞（需要登录）
```
POST /share/api/shares/:id/unlike
```

### 检查点赞状态（需要登录）
```
GET /share/api/shares/:id/like-status
```

### 获取我的分享（需要登录）
```
GET /share/api/my-shares
```

## 数据库表结构

### prompt_shares 表
- `id`: 主键
- `user_id`: 用户ID
- `username`: 用户名
- `title`: 标题
- `prompt`: 提示词内容
- `description`: 描述
- `like_count`: 点赞数
- `created_at`: 创建时间
- `updated_at`: 更新时间

### prompt_likes 表
- `id`: 主键
- `prompt_share_id`: 提示词分享ID
- `user_id`: 用户ID
- `created_at`: 创建时间
- 联合唯一索引：`(prompt_share_id, user_id)` 防止重复点赞

## 注意事项

1. 提示词内容不能为空
2. 标题长度限制：2-100 个字符
3. 不能为自己的分享点赞
4. 只能删除自己的分享
5. 提示词广场按点赞数倒序排列
6. 未登录用户可以浏览但不能点赞、分享
