支持所有文本类型文件（.txt, .log, .json等）

📡 API上传接口

接口地址

POST {{`{{ getApiUrl() }}`}}/tools/api/logs/upload 复制

请求参数

参数名 类型 说明
file 文件 要上传的日志文件
path 字符串 相对路径（可选，默认为空）

调用示例

curl -X POST {{`{{ getApiUrl() }}`}}/tools/api/logs/upload \
  -F "file=@/path/to/logfile.txt" \
  -F "path=mycoria/Windows"
复制 
$form = @{
    path = "mycoria/Windows"
    file = Get-Item -Path "C:\logs\test.log"
}
Invoke-RestMethod -Uri "{{`{{ getApiUrl() }}`}}/tools/api/logs/upload" `
  -Method Post -Form $form
