Figma Deliver

连接 Figma 设计与开发团队的强大工具

支持将 Figma 设计导出为开发可用的资源，提供完整的设计交付解决方案

功能特点

使用方法

通过 Figma 插件导出设计

  1. 安装插件

    在 Figma 桌面应用中，点击菜单 插件 > 开发 > 导入插件

    选择项目中的 figma-plugin/manifest.json 文件

  2. 配置连接

    打开插件设置，配置服务器地址：http://localhost:8080

    输入用户名和密码进行认证

  3. 导出设计

    在 Figma 中选择要导出的设计元素

    点击插件中的"导出到服务器"按钮

  4. 下载资源

    等待导出完成，可直接下载导出的文件

通过 Web 界面管理项目

  1. 启动服务

    运行 go run cmd/main.go 启动后端服务

    在浏览器中访问 http://localhost:8080

  2. 登录系统

    使用注册的用户名和密码登录系统

  3. 创建项目

    点击"新建项目"按钮

    输入项目信息和 Figma 文件链接

  4. 管理资源

    在项目详情页面查看和管理导出的设计资源

    支持预览、下载和批量操作

通过 API 集成到开发工作流

认证方式

使用 MCP Token 进行身份验证，无需登录状态：

  1. 登录 Web 界面 → 个人资料页面
  2. 生成或查看 MCP Token
  3. 在 API 调用中使用该 Token

核心接口

快速开始

import requests

# 1. 获取用户信息
response = requests.get('http://localhost:8080/api/your_token')
user_info = response.json()
print(f"用户: {user_info['data']['username']}")

# 2. 获取设计数据
params = {
    'file_key': 'ABC123',
    'root_node_id': '1:2'
}
response = requests.get(
    'http://localhost:8080/api/your_token/optimized_nodes',
    params=params
)
design_data = response.json()
print(f"节点数量: {design_data['data']['total_nodes']}")

# 3. 下载图片
params = {
    'file_key': 'ABC123',
    'node_id': '1:3',
    'format': 'png',
    'scale': 2.0
}
response = requests.get(
    'http://localhost:8080/api/your_token/download_image',
    params=params
)
with open('button.png', 'wb') as f:
    f.write(response.content)
 
// 1. 获取用户信息
const userResponse = await fetch('http://localhost:8080/api/your_token');
const userInfo = await userResponse.json();
console.log(`用户: ${userInfo.data.username}`);

// 2. 获取设计数据
const designUrl = new URL('http://localhost:8080/api/your_token/optimized_nodes');
designUrl.searchParams.append('file_key', 'ABC123');
designUrl.searchParams.append('root_node_id', '1:2');

const designResponse = await fetch(designUrl);
const designData = await designResponse.json();
console.log(`节点数量: ${designData.data.total_nodes}`);

// 3. 下载图片

imageUrl.searchParams.append('file_key', 'ABC123');
imageUrl.searchParams.append('node_id', '1:3');
imageUrl.searchParams.append('format', 'png');
imageUrl.searchParams.append('scale', '2.0');

const imageResponse = await fetch(imageUrl);
const imageBlob = await imageResponse.blob();
const imageUrl2 = URL.createObjectURL(imageBlob);
 
# 1. 获取用户信息
curl -X GET "http://localhost:8080/api/your_token"

# 2. 获取设计数据
curl -X GET "http://localhost:8080/api/your_token/optimized_nodes?file_key=ABC123&root_node_id=1:2"

# 3. 下载图片
curl -X GET "http://localhost:8080/api/your_token/download_image?file_key=ABC123&node_id=1:3&format=png&scale=2.0" \
  -o "button.png"

# 4. 清除缓存
curl -X POST "http://localhost:8080/api/your_token/clear_cache" \
  -H "Content-Type: application/json" \
  -d '{"file_key":"ABC123","root_node_id":"1:2"}'

安装与设置

后端服务

# 1. 确保已安装 Go 1.16 或更高版本
# 2. 克隆仓库
git clone <repository-url>

# 3. 进入 service 目录
cd service

# 4. 复制配置文件
cp configs/config.example.env configs/config.env

# 5. 启动服务
go run cmd/main.go

Figma 插件

# 1. 进入插件目录
cd figma-plugin

# 2. 打包插件
./package.bat

# 3. 在 Figma 中导入插件
# 菜单 > 插件 > 开发 > 导入插件
# 选择 manifest.json 文件

技术栈

  • 后端：Go + Gin 框架
  • 前端：Vue.js + Element UI
  • 插件：Figma Plugin API
  • 协议：MCP (Model Context Protocol)
