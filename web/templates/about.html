Figma Deliver

连接 Figma 设计与开发团队的强大工具

支持将 Figma 设计导出为开发可用的资源，提供完整的设计交付解决方案

功能特点

使用方法

通过 Figma 插件直接操作

  1. 安装插件

    在 Figma 中搜索并安装 "Figma Deliver" 插件

    或者通过开发者模式导入插件文件

  2. 连接服务

    在插件中配置 Figma Deliver 服务地址

    输入您的用户凭证或 API Token

  3. 选择设计元素

    在 Figma 画布中选择需要导出的设计元素

    插件会自动识别元素类型和建议配置

  4. 配置导出设置

    设置图片格式、缩放比例、命名规则等

    预览导出效果并调整参数

  5. 一键导出

    点击导出按钮，资源将自动上传到 Figma Deliver 服务

    在 Web 界面中查看和管理导出的资源

通过 MCP 协议集成 AI 工作流

  1. 配置 MCP 服务

    在支持 MCP 的 AI 编辑器（如 Cursor）的 mcp.json 文件中配置 Figma Deliver MCP 服务

    服务地址：https://figma-deliver.wekoi.cc/mcp/mcp_your_token_here

  2. 获取 MCP Token

    登录 Web 界面，在个人资料页面生成 MCP Token

    将 Token 配置到 MCP 客户端中

  3. AI 辅助设计处理

    使用 AI 编辑器直接与 Figma 设计进行交互

    获取设计预览、批量配置节点属性、智能生成配置

  4. 自动化工作流

    通过 AI 指令自动处理设计资源导出和优化

    支持批量操作和智能决策

通过 Web 界面管理项目

  1. 启动服务

    运行 go run cmd/main.go 启动后端服务

    在浏览器中访问 http://localhost:8080

  2. 登录系统

    使用注册的用户名和密码登录系统

  3. 创建项目

    点击"新建项目"按钮

    输入项目信息和 Figma 文件链接

  4. 管理资源

    在项目详情页面查看和管理导出的设计资源

    支持预览、下载和批量操作

MCP 协议 API 集成

MCP 协议介绍

Model Context Protocol (MCP) 是一个开放标准，用于 AI 应用与外部数据源的安全连接。

Figma Deliver 通过 MCP 协议提供以下能力：

  • 直接从 AI 编辑器访问 Figma 设计数据
  • 智能生成设计资源配置
  • 批量处理和优化设计元素
  • AI 辅助的设计决策和建议

MCP Token 认证

使用 MCP Token 进行身份验证，支持无状态 API 访问：

  1. 登录 Web 界面 → 个人资料页面
  2. 生成或查看 MCP Token
  3. 在 MCP 客户端或 API 调用中使用该 Token

MCP 功能接口

设计数据获取
get_preview - 获取 Figma 节点预览图
get_node_tree - 获取节点配置信息
get_ref_nodes - 获取依赖节点列表
配置管理
set_nodes_modify - 批量设置节点配置
get_modify_prompt - 获取 AI 配置提示词
clear_nodes_modifys - 清理节点修改

# MCP 客户端示例 (使用 mcp-client 库)
import asyncio
from mcp_client import MCPClient

async def main():
    # 连接 MCP 服务
    client = MCPClient("https://figma-deliver.wekoi.cc/mcp/mcp_your_token_here")
    await client.connect()
    
    # 获取设计预览
    preview = await client.call_tool(
        "get_preview",
        project_id=123,
        format="png",
        scale=2.0
    )
    
    # 批量配置节点
    await client.call_tool(
        "set_nodes_modify",
        project_id=123,
        modifys=[
            {"id": "1:2", "img_ext": "png", "res_mode": "attach"},
            {"id": "1:3", "img_ext": "svg", "res_mode": "sprite"}
        ]
    )
    
    await client.disconnect()

asyncio.run(main())

技术栈与特色

  • Figma 插件：JavaScript + Figma Plugin API，直接在设计工具中操作
  • MCP 协议：Model Context Protocol 支持，实现 AI 原生集成
  • 后端服务：Go + Gin 框架，高性能并发处理
  • Web 界面：Vue.js + Element UI，响应式设计
  • AI 集成：支持 Cursor 等 AI 编辑器直接访问
  • 智能化：AI 辅助的设计决策和配置生成

Figma 插件优势

  • 原生体验：直接在 Figma 中完成所有操作，无需切换工具
  • 实时同步：设计变更即时反映到导出配置中
  • 智能识别：自动识别设计元素类型并推荐最佳配置
  • 批量处理：支持选择多个元素进行批量配置和导出

MCP 协议优势

  • 无缝集成：AI 编辑器可直接访问 Figma 设计数据
  • 安全可靠：基于 Token 的认证机制，保障数据安全
  • 扩展性强：支持多种 MCP 客户端和 AI 应用
  • 标准化：遵循 MCP 开放标准，保证兼容性
