# Figma Deliver Plugin 用户指南

## 简介

Figma Deliver Plugin 是一个 Figma 插件，允许设计师直接从 Figma 界面导出设计到 Figma Deliver 服务。这个插件简化了设计到开发的工作流程，使设计师能够更轻松地与开发团队协作。

## 安装插件

### 从 Figma 插件商店安装

1. 打开 Figma 桌面应用
2. 点击菜单 `插件` > `浏览插件商店`
3. 搜索 "Figma Deliver"
4. 点击 "安装" 按钮

### 手动安装

1. 下载最新的 `.fig` 插件文件
2. 打开 Figma 桌面应用
3. 点击菜单 `插件` > `管理插件`
4. 点击 `+` 按钮，然后选择 `导入插件`
5. 选择下载的 `.fig` 文件

## 首次使用

### 连接到 Figma Deliver 服务

1. 在 Figma 中打开您的设计文件
2. 点击菜单 `插件` > `Figma Deliver`
3. 插件将打开认证界面
4. 输入 Figma Deliver 服务的地址（例如：`http://localhost:8080` 或 `https://your-figma-deliver-server.com`）
5. 输入您的用户名和密码
6. 点击 `登录` 按钮
7. 认证成功后，插件将自动切换到导出界面

## 导出设计

### 基本导出流程

1. 在 Figma 中选择要导出的设计元素（例如：Frame、Component 或 Group）
2. 启动 Figma Deliver 插件
3. 在导出界面中，您可以看到当前选择的元素信息
4. 如果需要，可以修改项目名称
5. 点击 `导出到 Figma Deliver` 按钮
6. 插件将开始导出过程，并显示进度信息
7. 导出完成后，您将看到成功消息和项目 ID

### 导出选项

- **项目名称**：为导出的设计设置一个名称，默认为 Figma 文件名
- **选择元素**：您可以选择任何 Figma 元素进行导出，包括 Frame、Component、Group 等

## 管理连接

### 切换服务器

1. 在插件界面中，点击右上角的 `设置` 按钮
2. 输入新的服务器地址
3. 输入您的用户名和密码
4. 点击 `登录` 按钮

### 重新认证

如果您的认证令牌过期或无效：

1. 点击右上角的 `设置` 按钮
2. 重新输入您的用户名和密码
3. 点击 `登录` 按钮

## 故障排除

### 认证问题

- **错误消息：认证失败**
  - 检查服务器地址是否正确
  - 确认用户名和密码是否正确
  - 确认 Figma Deliver 服务是否正在运行

- **错误消息：服务器连接失败**
  - 检查网络连接
  - 确认服务器地址是否正确
  - 确认服务器是否在线

### 导出问题

- **错误消息：导出失败**
  - 确保已选择有效的设计元素
  - 检查与服务器的连接
  - 确认认证令牌是否有效

- **错误消息：未选择任何元素**
  - 在 Figma 中选择至少一个元素，然后重试

## 最佳实践

- 导出前组织好您的设计，使用有意义的命名
- 选择最顶层的组件或框架进行导出，以确保包含所有必要的元素
- 定期更新插件以获取最新功能和修复

## 隐私和数据安全

- 插件仅在本地存储认证令牌和服务器地址
- 不会收集或上传任何设计数据，除非您明确启动导出操作
- 所有通信都使用您提供的服务器地址进行
